# ระบบใบรายชื่อนักเรียน

เปิด [หน้าเว็บ](https://bk14school.github.io/namelist/) เพื่อดูรายชื่อแยกชั้น กด **เลือกนักเรียน** เพื่อค้นหาและเลือกข้ามชั้นได้ รายชื่อที่เลือกจะเรียงจากชั้นต่ำไปสูงเสมอ และสามารถคัดลอก ส่งออก Excel หรือพิมพ์ได้

ในหน้าคัดเลือกสามารถบันทึกกิจกรรม การมาสาย และการผิดระเบียบลง Google Sheets พร้อมดูประวัติรายการได้ โดยไม่ต้องกรอกรหัสบันทึกรายการ

**การเข้าถึงข้อมูล:** เว็บแอป Google Apps Script ที่ใช้กับระบบนี้เปิดให้ทุกคนเข้าถึงได้ หากไม่ใช้รหัสบันทึกรายการ ผู้ที่เข้าถึงเว็บแอปจะอ่านและเพิ่มประวัติเหล่านี้ได้ ควรจำกัดสิทธิ์การใช้งานก่อนบันทึกเหตุการณ์จริง
