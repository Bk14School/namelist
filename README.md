# ระบบใบรายชื่อนักเรียน

เปิด [หน้าเว็บ](https://bk14school.github.io/namelist/) เพื่อดูรายชื่อแยกชั้น กด **เลือกนักเรียน** เพื่อค้นหาและเลือกข้ามชั้นได้ รายชื่อที่เลือกจะเรียงจากชั้นต่ำไปสูงเสมอ และสามารถคัดลอก ส่งออก Excel หรือพิมพ์ได้

เมื่อกด **เลือกนักเรียน** ระบบจะขอรหัสก่อนเปิดหน้าคัดเลือก กำหนดรหัสใน Google Sheets ชีท `config` โดยเพิ่มแถว `picker_pin` ในคอลัมน์ `key` และใส่รหัสในคอลัมน์ `value` รหัสจะไม่แสดงบนหน้าเว็บ และกรอกครั้งเดียวต่อการเปิดหน้าคัดเลือก

ในหน้าคัดเลือกสามารถบันทึกกิจกรรม การมาสาย และการผิดระเบียบลง Google Sheets พร้อมดูประวัติรายการได้ ประวัติแต่ละรายการพิมพ์รายชื่อ แก้ไขรายละเอียดและนักเรียน หรือลบได้ ระบบตรวจรหัสอีกครั้งทุกครั้งที่อ่านหรือเปลี่ยนประวัติ และยังสามารถคัดลอก ส่งออก Excel หรือพิมพ์รายชื่อที่เลือกตามลำดับชั้นจากต่ำไปสูง

ช่อง **ครูผู้บันทึก** เป็นข้อมูลไม่บังคับ กรอกตอนสร้างหรือแก้ไขรายการได้ ชื่อครูจะแสดงในประวัติและใบพิมพ์ ระบบเก็บไว้ในคอลัมน์ `ครูผู้บันทึก` ของชีท `รายการที่เลือก` โดยรายการเดิมยังอ่านได้ตามปกติ

## ใบขออนุญาตออกนอกบริเวณโรงเรียน

หลังกรอกรหัสเลือกนักเรียน ให้เปิดแท็บ **ตั้งค่าฟอร์ม** เพื่อใส่ชื่อรองผู้อำนวยการ รายชื่อครูฝ่ายกิจการนักเรียน (หลายคนได้) และครูประจำชั้นของแต่ละชั้น ระบบเก็บข้อมูลในชีท `ตั้งค่าใบอนุญาต`

เลือกนักเรียนข้ามชั้นแล้วเปิดแท็บ **ใบขอออกนอกบริเวณ** กรอกข้อมูลร่วม หรือแก้วันที่ เวลา ธุระ สถานที่ ครูฝ่ายกิจการ และข้อมูลผู้ปกครองแยกทีละคน บันทึกพร้อมกันได้สูงสุด 100 คน โดยสร้างคำขอแยกรายคนในชีท `ใบขอออกนอกบริเวณ` เบอร์โทรผู้ปกครองเป็นช่องไม่บังคับและแสดงในใบพิมพ์กับหน้าพิจารณา รายการที่บันทึกแล้วมีปุ่มพิมพ์หรือเปิด PDF (สองชุดต่อคนในหน้า A4 เดียว เพื่อฉีกแบ่งให้นักเรียนและโรงเรียน) ส่งลิงก์ผ่าน LINE และคัดลอกลิงก์ PDF สร้างในเบราว์เซอร์จากภาพของฟอร์ม เพื่อให้ตำแหน่งข้อความคงที่เมื่อเปิดบนมือถือหรือ iPad

ระบุความเห็นของครูที่ปรึกษาและครูฝ่ายกิจการเป็นรายคนก่อนบันทึก ใบพิมพ์จะทำเครื่องหมายในช่องที่เลือก และใช้ฟอนต์ Sarabun พร้อมชื่อโรงเรียน “โรงเรียนบ้านคลอง 14 สพป.นครนายก” หากนักเรียนไม่กลับเข้ามาในวันนั้น ให้เลือก **ไม่กลับเข้ามาในโรงเรียนในวันนั้น** แทนการกรอกเวลากลับ ระบบจะระบุข้อความนี้ในใบพิมพ์และหน้าพิจารณา

รองผู้อำนวยการต้องกรอกรหัสอนุมัติแยกก่อนเปิดลิงก์และสามารถอนุมัติหรือไม่อนุมัติเป็นรายคนหรือทุกคนที่รอพิจารณา กำหนดรหัสนี้ในชีท `config` โดยเพิ่ม `deputy_pin` ในคอลัมน์ `key` และใส่รหัสในคอลัมน์ `value` ระบบไม่ส่งค่า `deputy_pin` หรือ `picker_pin` กลับไปกับข้อมูลตั้งค่าทั่วไป

ไฟล์ [Code.gs](Code.gs) เป็นโค้ดของ Google Apps Script ที่ใช้คู่กับหน้าเว็บ ต้องอัปเดต deployment ของเว็บแอปหลังแก้ไฟล์นี้
